What Is LM Studio?

LM Studio is a desktop application that allows users to discover, download, and run large language models directly on their computers. It provides a graphical interface for experimenting with AI without needing advanced programming knowledge.

With LM Studio, Mac users can explore compatible models, chat with AI, work with documents, and create local API connections for development projects.

How to Install LM Studio on Mac

Step 1: Check Your Mac Requirements

Before installing LM Studio, check your Mac's hardware and operating system.

  • Apple Silicon Mac (M1, M2, M3, or M4).
  • macOS 14.0 or newer.
  • 16GB or more RAM recommended.
  • Enough free storage for AI models.

Note: Current LM Studio requirements do not support Intel-based Macs.

Step 2: Visit the Official Website

Open your browser and visit the official LM Studio download page. Select the macOS version to get the appropriate installer.

Official LM Studio Download →

Step 3: Download the Installer

Click the macOS download option and wait for the installer file to finish downloading. Make sure you download the application from the official developer website.

Step 4: Install LM Studio

Open the downloaded DMG file. Follow the installation instructions and drag LM Studio into your Applications folder if prompted.

After installation, open the Applications folder and launch LM Studio.

Step 5: Download Your First AI Model

Once LM Studio opens, navigate to the Discover section. Search for a compatible model such as Llama, Qwen, Gemma, or another supported model.

Choose a model size that fits your Mac's available memory and storage, then download it.

Step 6: Load the AI Model

Open the downloaded model from the My Models section. Load it into memory and wait until the application indicates that it is ready.

Step 7: Start Chatting With AI

Open the Chat section and select your loaded model. Type a question or prompt into the conversation window and start interacting with your local AI assistant.

How to Use LM Studio Offline

One useful feature of LM Studio is its ability to operate offline after downloading the application, required runtime, and model files.

Once everything is downloaded, you can load a compatible local model and chat without needing an active internet connection for inference.

Using LM Studio for Development

Developers can also use LM Studio to connect local language models with their applications. Its local server offers OpenAI-compatible API endpoints, allowing supported software to communicate with locally running models.

lms server start

The command above starts the LM Studio local server through its CLI, provided the CLI is configured.

Helpful tip: AI models can require substantial memory. Start with a smaller model and increase model size only when your Mac has enough available resources.

Common LM Studio Installation Problems

  • App does not open: Check macOS compatibility and installation permissions.
  • Model download is slow: Check your internet connection and available disk space.
  • Model fails to load: Try a smaller model that requires less memory.
  • Slow AI responses: Use a suitable model size and close unnecessary applications.
  • Server connection problems: Check the local server status and API configuration.
