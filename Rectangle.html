Product overview

What Is Rectangle for Mac?

A practical window manager that helps Mac users arrange applications, manage screen space, and move between tasks with less manual resizing.

A simpler way to manage Mac windows

Rectangle is a window management application for macOS. It allows users to move and resize application windows into useful positions using keyboard shortcuts or screen-edge snapping. Instead of repeatedly dragging window borders, you can quickly arrange your desktop into a layout that suits your work.

This can be particularly helpful when working with multiple applications at the same time. You might keep a browser on one side of the display, a code editor on the other, and a communication app in a smaller corner.

Organize windows with keyboard shortcuts

One of Rectangle's main strengths is its keyboard-driven workflow. You can assign or use shortcuts to move the active window to different screen positions. Common arrangements include:

  • Move a window to the left or right half of the display.
  • Place windows in the top-left or top-right corners.
  • Arrange windows in the bottom-left or bottom-right corners.
  • Maximize a window or move it to other screen positions.
  • Use thirds and other supported layouts for wider workflows.

Rectangle also supports repeating certain shortcuts to cycle through window sizes. This helps reduce the number of individual key combinations users need to remember.

Snap windows by dragging

If you prefer using a mouse or trackpad, Rectangle provides snap areas. Drag a window toward a screen edge or corner and the application displays a preview of the resulting position. Release the window to apply the layout.

This interaction will feel familiar to people who have used window snapping on other desktop operating systems. Rectangle also supports portrait display layouts, making it useful for users who work with vertically oriented monitors.

Make multitasking more comfortable

Managing several windows manually can interrupt concentration. Rectangle helps reduce that friction by providing repeatable layouts. You can compare documents side by side, reference a website while writing, or keep a terminal visible while working in an editor.

It does not automatically tile every application as a traditional tiling window manager might. Instead, it gives you direct control over where individual windows should go. This makes it a straightforward option for people who want predictable window placement without learning a complex tiling system.

Rectangle and Rectangle Pro

The standard Rectangle application is free and open source. It provides common window positions, keyboard shortcuts, and drag-to-snap functionality.

Rectangle Pro is a separate paid application with additional customization. Its features include custom shortcuts for different window sizes and positions, quicker snapping, configurable snap targets, and workspace arrangements. It is worth comparing both editions before deciding which one fits your workflow.

Who should consider Rectangle?

Rectangle can be useful for developers, designers, students, researchers, office workers, and anyone who frequently switches between several Mac applications. It is especially helpful on larger displays where arranging multiple windows can make better use of available screen space.

Frequently asked questions

Rectangle FAQ

Answers to common questions about Rectangle and its window management features.

1. What is Rectangle for Mac?

Rectangle is a macOS window manager that lets users move and resize application windows with keyboard shortcuts or drag-to-snap areas.

2. Is Rectangle free to use?

Yes. The standard Rectangle application is free and open source. Rectangle Pro is a separate paid application with additional features.

3. Does Rectangle work on Windows?

No. Rectangle is designed for macOS and is not a Windows window management application.

4. Can I use Rectangle with keyboard shortcuts?

Yes. Keyboard shortcuts are a core part of Rectangle. You can use and configure commands for moving and resizing application windows.

5. Does Rectangle support multiple monitors?

Yes. Rectangle includes window actions for working across displays, helping users organize applications in multi-monitor environments.

6. What is the difference between Rectangle and Rectangle Pro?

Rectangle provides common window management features for free. Rectangle Pro adds advanced customization, including custom window positions, snap targets, and workspace features.

7. What macOS version does Rectangle require?

The current main release requires macOS 14 or newer. Older releases are available for certain earlier macOS versions. Check the official compatibility information before downloading.

8. Is Rectangle a tiling window manager?

Rectangle is primarily a window snapping and positioning tool. It moves windows into selected positions rather than automatically arranging every window as a traditional tiling window manager does.
