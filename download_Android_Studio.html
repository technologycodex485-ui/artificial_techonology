01 / Introduction

What is Android Studio?

Android Studio is Google's official integrated development environment (IDE) for Android application development. It provides a complete workspace where developers can create projects, edit source code, build applications and test them on virtual or physical Android devices.

The software includes a code editor, Gradle build tools, Android SDK management, debugging features, layout tools and Android Emulator integration.

Installing Android Studio on macOS is straightforward: download the correct DMG installer, move the application into Applications and complete the first-run setup wizard.

One IDE for your Android development workflow.

Android Studio brings project editing, SDK configuration, building, debugging and app testing together in one development environment.

02 / Before downloading

Check your Mac's system requirements

Before downloading Android Studio, make sure your Mac has a supported processor, enough memory and sufficient free disk space.

⌘

macOS Version

Minimum macOS 12. Check the official requirements page for current compatibility information.

▤

RAM

At least 8 GB for Android Studio alone. 16 GB minimum when using the Android Emulator.

◈

Processor

Apple M1 or newer, or a supported Intel processor. Intel Mac support is being phased out.

▣

Storage

At least 8 GB of free space for Studio, or 16 GB when using the Emulator.

▱

Display

Minimum screen resolution of 1280 × 800. A larger display is more comfortable.

⚙

Recommended Setup

32 GB RAM, modern Apple silicon and an SSD with 32 GB or more free space.

03 / Step-by-step tutorial

How to download Android Studio on Mac

Follow these steps to download the official installer and complete the initial installation.

01

Open the Official Android Studio Website

Launch Safari, Chrome or another browser on your Mac. Visit Google's official Android Studio download page: developer.android.com/studio .

  • Find the latest stable Android Studio release.
  • Review the download terms and conditions.
  • Choose the installer that matches your Mac.
02

Choose the Correct Mac Installer

Android Studio provides different DMG downloads for Apple silicon and Intel processors.

  • Choose Mac with Apple chip for M-series Macs.
  • Choose Mac with Intel chip for supported Intel Macs.
  • Save the downloaded DMG file to your Mac.
03

Open the DMG Installer

After the download finishes, open Finder and go to your Downloads folder. Double-click the Android Studio DMG file to open the installer.

  • Wait for the installer window to appear.
  • Locate the Android Studio application icon.
  • Keep the installer open while copying the app.
04

Move Android Studio into Applications

Drag the Android Studio application icon into the Applications folder shown in the installer window. Wait for the copy process to finish.

  • Open Finder and select Applications.
  • Find Android Studio in the application list.
  • Launch the app to begin setup.
05

Complete the Setup Wizard

When Android Studio starts for the first time, choose whether to import previous settings. Continue through the Setup Wizard.

  • Review the setup options.
  • Choose the recommended installation type if suitable.
  • Accept the required SDK licenses.
  • Allow the required development components to download.
06

Finish Installation and Start Coding

Once the required components are installed, open Android Studio and create a new project. Select a template and configure your application.

  • Choose a project template.
  • Set the project name and package details.
  • Wait for Gradle synchronization to finish.
  • Start building your Android application.
04 / Select your installer

Apple silicon or Intel: which version do you need?

Your Mac's processor determines which Android Studio installer you should choose. Selecting the correct package helps avoid compatibility problems.

Mac with Apple chip

Choose this version if your Mac uses an Apple M-series processor, such as M1, M2, M3, M4 or a newer generation.

APPLE SILICON / ARM64

Mac with Intel chip

Choose the Intel DMG if you have a supported Intel Mac. Google is phasing out Intel Mac support, so check the latest compatibility requirements.

INTEL / X86_64
How to check your processor: Click the Apple menu in the top-left corner of your screen, select About This Mac and look for the Chip or Processor information.
05 / After installation

Set up the Android SDK and Emulator

Installing the IDE is only the first part of the process. Android Studio also needs the appropriate development packages to build and test Android applications.

Android SDK

Provides the platform tools, APIs and development components required to build Android applications.

SDK Platform Tools

Includes tools such as ADB for communicating with Android devices and managing development tasks.

Android Emulator

Lets you run and test Android apps using virtual device configurations without requiring a physical phone.

07 / Frequently asked questions

Android Studio on Mac: FAQs

1. Is Android Studio available for Mac?

Yes. Android Studio is available for macOS. Google provides separate download options for Apple silicon and supported Intel Macs.

2. Is Android Studio free to download?

Android Studio is available as a free download from the official Android Developers website.

3. How much RAM do I need?

Google's listed minimum is 8 GB for Android Studio alone and 16 GB for Android Studio with the Android Emulator. More memory is recommended for larger projects.

4. Can I install Android Studio on an M1 Mac?

Yes. Choose the Mac with Apple chip installer for an Apple silicon Mac.

5. Can I use Android Studio without an Emulator?

Yes. You can deploy and test applications on a compatible physical Android device instead of using a virtual device.

6. Why does Android Studio download SDK components?

The SDK includes the APIs and tools needed to compile, build, debug and test Android applications.

7. Where should I download Android Studio?

Use the official Google Android Developers website at developer.android.com/studio.
