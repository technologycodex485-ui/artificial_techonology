01 / Introduction

What is Liuer?

A desktop search tool for people who need more control over finding information on their Mac.

Liuer is a file and content search application for macOS. It helps users locate files through filename searches, advanced matching options, and filters. Its Pro edition adds the ability to search inside supported file contents.

Instead of manually opening folders one by one, you can enter a search term and narrow the results using options such as file type, date, size, extension, and path. Regular expressions and Boolean conditions can also help make searches more precise.

Liuer is useful for developers, designers, researchers, students, and anyone who regularly works with large collections of documents or project files.

Designed for focused searching

Liuer combines filename search with optional content search, giving Mac users another way to locate information across their indexed files.

03 / Getting Started

How to start using Liuer

Set up your search environment and begin locating files.

STEP 01

Install the application

Download Liuer from its official website or the Mac App Store, then install it on a supported Mac.

STEP 02

Set up indexing

Choose an index directory if using the App Store version. The standalone version requires Full Disk Access for a complete search index.

STEP 03

Search your files

Enter a filename or keyword, then refine the results using search modes and available filters.

06 / Help Center

Frequently asked questions

Quick answers to common questions about Liuer.

1. What is Liuer used for?

Liuer is a macOS utility for finding files by name and searching inside supported file contents with its Pro features.

2. Is Liuer available for Windows?

Liuer is designed for macOS. Its listed system requirements are macOS 13.0 Ventura or later.

3. Does Liuer support content search?

Yes. Full-text content search is included in Liuer Pro, while the Free version focuses on filename search.

4. Can Liuer search inside archives?

Liuer Pro supports searching supported archive formats, including ZIP and several compressed formats.

5. Does Liuer send my files to a server?

The developer describes indexing and searching as local operations performed on your Mac.

6. Where can I download Liuer?

Visit the official Liuer website for its standalone download and Mac App Store options.
