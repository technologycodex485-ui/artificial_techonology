Introduction

What Is Amphetamine for Mac?

A convenient way to manage sleep behavior and keep your Mac active during important tasks.

Amphetamine is a free macOS application developed by William Gustafson. It is designed to prevent your Mac from entering sleep mode while you are performing tasks that require the computer to remain awake. The application provides a simple menu bar interface for starting and managing keep-awake sessions.

macOS normally manages sleep and energy settings to conserve power. This is useful for everyday use, but there are situations when automatic sleep can interrupt a task. For example, you might be downloading a large file, running a lengthy process, presenting information, or using an application that needs uninterrupted computer activity.

A Simple Way to Prevent Automatic Sleep

Amphetamine allows users to start a session manually or configure one to run for a selected period. You can choose an indefinite session, set a duration, specify an end time, or keep the Mac awake while a selected application is running.

Flexible Controls for Different Tasks

The app offers more than a basic on-and-off switch. Depending on your session settings, you can control whether the display sleeps, whether the screen saver activates, and how the Mac behaves during a keep-awake session.

Automation With Triggers

Amphetamine includes a feature called Triggers. These allow you to define conditions under which a keep-awake session starts automatically. Conditions can include connected devices, running applications, power status, network details, and other supported system states.

Session Options

Choose How Long Your Mac Stays Awake

Amphetamine provides several ways to manage a keep-awake session according to the task you are performing.

Indefinite Session

Start a session that continues until you manually end it. This is useful for tasks without a predictable completion time.

Timed Session

Select a duration for your session. Amphetamine can automatically end it when the chosen time has passed.

App-Based Session

Keep your Mac awake while a selected application or process is running, according to the configured options.

Smart Automation

Automate Your Keep-Awake Sessions With Triggers

Triggers let you create conditions that start a session automatically. Rather than activating the app manually every time, configure a rule around your regular workflow.

This can be useful when connecting an external display, running a specific application, or using a particular network connection.

Help & Information

Frequently Asked Questions

Find answers to common questions about Amphetamine and its keep-awake functionality.

1. What is Amphetamine software used for?

Amphetamine is a macOS utility that prevents your Mac from automatically going to sleep during configured keep-awake sessions.

2. Is Amphetamine free?

Yes. The Mac App Store listing describes Amphetamine as free, without advertisements or in-app purchases.

3. Can Amphetamine keep my Mac awake for a specific time?

Yes. You can select a duration or specify a time when the keep-awake session should end.

4. Can Amphetamine work automatically?

Yes. Its Triggers feature can start keep-awake sessions when configured conditions are met, such as an application running or an external display being connected.

5. Can I let the display sleep while keeping the Mac awake?

Yes. Amphetamine provides options to allow display sleep while keeping the system awake, depending on the selected session settings.

6. Does Amphetamine work on Windows?

This Amphetamine application, developed by William Gustafson, is designed for macOS and is not the Windows version of a keep-awake utility.

7. Can Amphetamine keep a MacBook awake with its lid closed?

Amphetamine supports closed-display operation on compatible MacBook configurations. Check the developer's current documentation for the requirements and behavior of your particular Mac model.

8. Who develops Amphetamine?

Amphetamine is developed by William Gustafson and is available through the Mac App Store.
