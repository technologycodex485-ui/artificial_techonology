01 / Introduction

Bring the Java ecosystem to your Mac

Java is a widely used programming language and software platform. Developers use it to create desktop applications, enterprise systems, backend services, and many other types of software.

Installing Java on macOS is straightforward when you choose the right package. If you plan to write and compile Java programs, you generally need the Java Development Kit (JDK). If you only need Java to run a particular application, check that application's requirements before choosing a runtime.

This guide walks through downloading the installer, completing the setup, and checking your Java installation.

Before you begin

Check whether your Mac uses Apple Silicon or an Intel processor. The download architecture must match your computer.

03 / Installation process

How to install Java on macOS

Once you have downloaded the correct JDK installer, follow these steps to complete the installation.

1

Download the JDK installer

Open the official Oracle Java downloads page. Select the Java release you need, then choose the macOS installer that matches your processor. Download the .dmg package.

2

Open the downloaded file

Go to your Downloads folder and double-click the downloaded .dmg file. A mounted installer window should appear in Finder.

3

Launch the installer package

Double-click the JDK .pkg installer inside the mounted disk image. Follow the on-screen instructions and select Continue when prompted.

4

Approve the installation

Select Install. macOS may request an administrator username and password. Enter the required credentials to allow the installer to continue.

5

Finish the setup

Wait for the installer to complete and display its confirmation message. You can then close the installer and eject the mounted disk image.

6

Verify your Java installation

Open Terminal from Applications → Utilities. Enter the version command shown below and press Return.

04 / Terminal verification

Check whether Java is installed correctly

Terminal lets you confirm which Java version macOS is using. Run the following command:

Check the installed Java runtime version:

java -version

If you installed the JDK, check the Java compiler too:

javac -version

You can also list installed JDK versions with:

/usr/libexec/java_home -V
01.

java -version

Displays the Java runtime version currently available to your Terminal session.

02.

javac -version

Checks whether the Java compiler is installed and accessible from the command line.

03.

java_home

Helps identify the JDK installations registered with macOS.

05 / Troubleshooting

Common Java installation problems

Java command not found

If Terminal cannot find Java, confirm that the installation completed successfully. Check your installed JDK versions using /usr/libexec/java_home -V. Also make sure you downloaded a package compatible with your Mac.

Wrong installer architecture

An Intel installer and an Apple Silicon installer are not interchangeable choices. Check About This Mac and download the appropriate macOS package.

Java is installed, but javac is unavailable

The Java runtime and the full JDK are different. The javac compiler is included with the JDK, so developers should install a JDK rather than relying only on a runtime.

Which Java version should I install?

Choose a version compatible with your project, framework, or application. If you are starting a new project, consider a supported long-term support release and review its compatibility requirements.
