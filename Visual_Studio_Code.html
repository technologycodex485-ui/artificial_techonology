01 / Introduction

A flexible code editor for your Mac

Visual Studio Code, commonly known as VS Code, is a popular source-code editor developed by Microsoft. It provides a practical workspace for writing, editing, and managing code across many programming languages.

Its features include syntax highlighting, code completion, debugging support, an integrated terminal, source control integration, and a large extension marketplace.

Whether you are learning web development, working on Python projects, or maintaining an existing codebase, VS Code can be configured to support your workflow.

Why choose VS Code?

Start with a clean editor and add the extensions, themes, and tools you need. AI-powered features are available as optional additions; the core editor does not require an account to get started.

03 / Installation

How to download and install VS Code on Mac

Follow these simple steps to get the editor running on your Mac computer.

STEP 01

Visit the official download page

Open the official Visual Studio Code download website. Find the macOS section and review the available Mac versions.


Visit Official Download Page ↗
STEP 02

Choose the correct Mac build

Select the Apple silicon version if your Mac uses an M-series processor. Choose the Intel version for an Intel-based Mac. The Universal build supports both processor families.

STEP 03

Download the DMG file

Click the appropriate download option and wait for the Visual Studio Code disk image (.dmg) file to finish downloading.

STEP 04

Open the downloaded installer

Open your Downloads folder and double-click the downloaded DMG file. A new installation window will appear.

STEP 05

Move VS Code into Applications

Drag the Visual Studio Code application icon into your Mac's Applications folder. Wait for the copy process to finish.

STEP 06

Launch Visual Studio Code

Open Applications, find Visual Studio Code, and double-click it. You can also locate the app using Spotlight search.

STEP 07

Start your first project

Select Open Folder to work with an existing project, or create a new folder for your first coding project.

04 / Developer Tip

Open projects from Terminal

You can configure the VS Code command-line tool to launch the editor directly from your Mac terminal. This is useful when switching between project folders.

# Open VS Code
code .

# Open a project folder
cd my-project
code .

First, open VS Code, press Cmd + Shift + P, and run "Shell Command: Install 'code' command in PATH".

05 / Frequently Asked Questions

Common questions about VS Code for Mac

1. Is Visual Studio Code free for Mac?

Yes. The core Visual Studio Code editor is free to download and use. Optional services and extensions may have their own terms or pricing.

2. Does VS Code work on Apple silicon?

Yes. Visual Studio Code supports Apple silicon Macs. You can choose an Apple silicon-specific installer or the Universal build.

3. Can I install VS Code on an Intel Mac?

Yes. An Intel-specific Mac download is available from the official download page. Check the current macOS requirements before installing.

4. How do I update Visual Studio Code?

VS Code supports automatic updates. When an update is available, follow the application's update prompt.

5. Can beginners use Visual Studio Code?

Absolutely. Beginners can start with basic editing and gradually explore extensions, debugging, terminal tools, and other development features.
