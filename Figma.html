01 / Introduction

What is Figma?

Figma is a collaborative platform for creating digital designs, prototypes, presentations, and product experiences.


Visit Official Figma ↗

Figma is a cloud-based design platform widely used by UI designers, UX professionals, product teams, developers, and creative agencies. It provides a shared environment where people can create interface layouts, build design systems, and explore interactive product ideas.

One of Figma's defining strengths is real-time collaboration. Multiple team members can work in the same design file, leave comments, share feedback, and review changes without constantly exchanging separate files.

Figma is useful throughout the product development process. Designers can plan an interface, create reusable components, connect screens into interactive prototypes, and share their work with developers and stakeholders.

More than a design canvas

Figma's product ecosystem includes Figma Design for interface creation, FigJam for collaborative brainstorming, Dev Mode for developer handoff, and Figma Slides for presentations. Other products and tools extend these workflows into additional creative and publishing tasks.

Because much of the workflow is browser-based, teams can share files and collaborate across different locations. Desktop applications are also available for supported systems.

03 / Real-world applications

What can you create with Figma?

Figma supports many kinds of digital design projects. Its flexible canvas and collaboration tools make it useful for both individual designers and larger product teams.

Website design

Design landing pages, business websites, dashboards, online stores, and responsive website layouts. Designers can explore different page structures before development begins.

Mobile app interfaces

Create screens for mobile applications, plan navigation, organize reusable interface components, and demonstrate user journeys with interactive prototypes.

UX research and planning

Use FigJam to map user journeys, organize research insights, create flow diagrams, and brainstorm solutions with teammates.

Branding and visual systems

Build visual guidelines, design libraries, reusable assets, and consistent interface patterns for digital products.

Developer collaboration

Share designs and use Dev Mode to communicate measurements, assets, component details, and implementation requirements.

05 / Plans and subscriptions

Is Figma free to use?

Figma offers a free Starter plan alongside paid plans designed for professional teams and organizations.


View Official Pricing ↗

Figma's Starter plan is a way to explore its core design and collaboration tools without an initial subscription. It is suitable for people learning the platform and working on smaller personal projects.

The Professional plan provides additional capabilities such as unlimited files and projects for a single team, shared design libraries, advanced prototyping, and enhanced developer handoff features.

Organization and Enterprise plans are designed for larger teams that need broader administration, security, shared resources, and organization-wide design systems.

Figma uses different seat types, including Full, Dev, and Collab seats, to match different workflows. Pricing and included features can change, so review the official pricing page before choosing a subscription.

06 / Common questions

Frequently asked questions

Here are answers to common questions about Figma and its design tools.

What is Figma mainly used for?

Figma is used for user interface design, UX planning, interactive prototyping, design systems, collaboration, and product development workflows.

Is Figma suitable for beginners?

Yes. Beginners can start with simple layouts, shapes, text, and frames before learning components, auto layout, and advanced prototyping.

Can I use Figma for free?

Yes. Figma offers a Starter plan with limited access to its products and features. Paid plans provide additional tools and team capabilities.

Can multiple people work in Figma together?

Yes. Figma supports real-time collaboration, allowing multiple users to work in shared files, provide feedback, and review designs.

What is FigJam?

FigJam is Figma's collaborative online whiteboard. Teams can use it for brainstorming, diagrams, workshops, planning, and organizing ideas.

What is Figma Dev Mode?

Dev Mode is a developer-focused workspace for inspecting designs, viewing properties and measurements, accessing assets, and supporting design-to-code handoff.

Can Figma create interactive prototypes?

Yes. You can connect frames, configure interactions, add transitions, and preview how a proposed interface might behave.

Does Figma work in a web browser?

Yes. Figma supports browser-based workflows, and desktop applications are also available for supported operating systems.
