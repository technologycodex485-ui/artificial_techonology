// 01 — Introduction

What Is Ghostty?

A terminal emulator designed to combine performance, modern terminal capabilities, and a desktop-native experience.

Ghostty is a fast, feature-rich, cross-platform terminal emulator for macOS and Linux. Created by Mitchell Hashimoto, it aims to deliver a terminal experience that feels at home on each operating system while offering modern rendering and terminal features.

A terminal emulator provides an interface where users interact with command-line shells and programs. Developers use terminals for tasks such as managing files, running scripts, working with Git, building applications, and connecting to remote systems.

Ghostty combines a shared terminal core with native application interfaces. Its rendering uses Metal on macOS and OpenGL on Linux. This architecture helps it deliver a responsive interface while maintaining support for modern terminal capabilities.

Whether you are a software developer, system administrator, or command-line enthusiast, Ghostty offers a customizable environment for everyday terminal work.

// 03 — Customization

Make the Terminal Your Own

Ghostty supports a text-based configuration file with hundreds of options. You can adjust colors, fonts, window behavior, keybindings, and other preferences.

The following is a simple illustrative configuration example. You can adapt settings to your own environment.

# Example Ghostty configuration

font-family = JetBrains Mono

font-size = 14

theme = dark

window-padding-x = 12

window-padding-y = 12

shell-integration = detect

# Save your preferences and restart if needed

Note: Configuration options and accepted values depend on the installed Ghostty version. Consult the official configuration reference before applying settings.

// 06 — FAQ

Frequently Asked Questions

What is Ghostty used for?

Ghostty is a terminal emulator used to run command-line shells and tools. Developers use it for programming, Git operations, scripts, system administration, and other terminal-based tasks.

Is Ghostty available for Windows?

Ghostty's official desktop application supports macOS and Linux. Windows desktop support has been planned for the future; check the official website for updates.

Is Ghostty open source?

Yes. Ghostty is an open-source project. Its source code and contribution information are available through its official GitHub repository.

Does Ghostty support GPU acceleration?

Yes. Ghostty uses Metal for rendering on macOS and OpenGL on Linux.

Can I customize Ghostty's appearance?

Yes. You can configure themes, fonts, colors, window settings, and other preferences using its configuration file.

Does Ghostty support multiple terminal sessions?

Yes. Ghostty supports multiple windows, tabs, and split panes to help organize different terminal sessions.
