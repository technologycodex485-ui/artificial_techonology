Your Journey to Node.js Starts Here

Whether you are a beginner or an experienced developer, installing Node.js on your Mac is an important step toward building modern web applications.

What Is Node.js?

Node.js is an open-source JavaScript runtime environment that allows developers to execute JavaScript outside a web browser. It is commonly used to build web servers, APIs, command-line tools, and backend applications.

Node.js uses Google's V8 JavaScript engine and provides tools that make it possible to create fast and scalable applications.

Why Install Node.js on Mac?

macOS provides a convenient development environment. Node.js makes it easier to create and test JavaScript projects directly from your Mac.

Web Development

Create modern websites and full-stack applications.

Package Management

Use npm to install and manage JavaScript packages.

Build APIs, servers, and backend services.

Step 1: Check Your Mac Architecture

Before installing Node.js, identify which processor your Mac uses.

  1. Click the Apple menu in the top-left corner.
  2. Select About This Mac.
  3. Check whether your Mac uses Apple Silicon or Intel.

This helps you select the correct installation package when downloading Node.js.

Step 2: Download Node.js for Mac

Visit the official Node.js website to download the macOS installer. For most users, the LTS (Long-Term Support) release is the recommended starting point.

  1. Open the official Node.js download website.
  2. Select the macOS download option.
  3. Choose the appropriate installer for your Mac.
  4. Download the installer package.
Important: Download Node.js from the official website to ensure you get a trusted installer.
Get Node.js for Mac →

Step 3: Install Node.js on macOS

After downloading the installer, follow these steps to complete the installation.

  1. Open the downloaded .pkg installer file.
  2. Read the installation introduction.
  3. Accept the software license agreement.
  4. Select the installation destination if prompted.
  5. Click Install and provide administrator permission if required.
  6. Wait for the installation to finish.
  7. Close the installer when the process is complete.

Node.js and npm should now be available through Terminal.

Step 4: Verify Node.js Installation

Open Terminal on your Mac. You can find it through Spotlight Search or inside Applications and Utilities.

Enter this command:

node -v

This displays your installed Node.js version. Next, check npm: 

npm -v

If both commands display version numbers, the installation was successful.

Step 5: Install Node.js Using Homebrew

Homebrew is a popular package manager for macOS. If you already have Homebrew installed, you can install Node.js through Terminal.

Check Homebrew

brew --version

Install Node.js

brew install node

Verify Installation

node -v
npm -v

Homebrew is convenient for developers who prefer managing software through Terminal.

Step 6: Install Node.js Using NVM

NVM (Node Version Manager) lets you install and switch between multiple Node.js versions. It is especially useful when working on projects that require different Node.js releases.

Install NVM

Follow the official NVM installation instructions to install and configure it on macOS.

Official NVM Documentation

Install the Latest LTS Version

nvm install --lts

Use the Installed LTS Version

nvm use --lts

Check Node.js Version

node -v
NVM is a useful choice when you need to manage different Node.js versions for different projects.

Step 7: Create Your First Node.js Program

Once Node.js is installed, you can create a simple JavaScript application.

Create a Project Folder

mkdir my-node-project
cd my-node-project

Create a JavaScript File

touch app.js

Add This Code to app.js

console.log("Hello from Node.js on Mac!");

Run Your Program

node app.js

You should see the message displayed in Terminal. Congratulations! Your first Node.js program is running.

Common Node.js Installation Problems

1. Command Not Found

If Terminal displays a command-not-found message, check whether Node.js is installed correctly and whether its installation directory is available in your PATH.

2. npm Permission Errors

Permission errors can occur when installing global npm packages. Consider using NVM to manage Node.js and npm without changing system directory permissions.

3. Wrong Node.js Version

Some projects require a specific Node.js version. Use a version manager such as NVM to switch between compatible releases.

Conclusion

Installing Node.js on Mac is a straightforward process. You can use the official macOS installer, Homebrew, or NVM depending on your development needs.

After installation, verify Node.js and npm through Terminal and create your first JavaScript program. With Node.js ready, you can begin building websites, APIs, and modern software applications.
