How to Install Jan AI on Mac

Discover how to download, install, and start using Jan AI on your Mac with this beginner-friendly guide.

What Is Jan AI?

Jan AI is an open-source artificial intelligence desktop application that allows users to interact with AI models directly from their computers. It provides a simple interface for chatting, exploring language models, and working with AI tools.

One of its main advantages is the ability to run supported AI models locally. This means you can use compatible models without relying on a cloud service for every conversation.

Why Use Jan AI on Mac?

Jan AI is a useful option for Mac users who want more control over their AI experience. Its features include:

  • Run compatible AI models locally.
  • Explore different open-source language models.
  • Use AI without a subscription for local models.
  • Connect supported cloud AI providers.
  • Manage conversations through a desktop interface.
  • Work with AI even when offline after setup.

System Requirements for Jan AI

Before installing Jan AI, check that your Mac meets the current requirements.

  • macOS 13.6 or later.
  • Apple Silicon processor (M1, M2, M3, or M4).
  • At least 8GB RAM for smaller models.
  • 10GB or more available storage space.
  • Internet connection for downloading the app and models.
Important: Current Jan local-model support is designed for Apple Silicon Macs. Intel Macs are not supported for local inference with the current bundled engine.

How to Install Jan AI on Mac

Follow these simple steps to install Jan AI on your Apple Silicon Mac.

Step 1: Visit the Official Jan Website

Open your preferred web browser and visit the official Jan download website. Find the macOS download option.

Visit Official Website

Step 2: Download Jan AI

Select the macOS version and download the Jan installer. The downloaded file should have a .dmg extension.

Step 3: Open the DMG File

Once the download finishes, open your Downloads folder and double-click the Jan DMG installer. Wait for the installation window to appear.

Step 4: Move Jan to Applications

Drag the Jan application icon into your Applications folder. This copies the application to your Mac.

Step 5: Launch Jan AI

Open Finder, navigate to Applications, and double-click Jan. Follow any macOS security prompts if they appear.

Step 6: Download an AI Model

After opening Jan, visit the Hub from the sidebar. Browse the available models and choose one that fits your Mac's available memory.

Step 7: Start Chatting

Select your downloaded model, open a new conversation, and enter your first prompt. Jan AI is now ready to use.

Common Jan AI Installation Problems

Jan AI Does Not Open

Check your macOS version and confirm that you downloaded the correct installer. Also check macOS security settings.

AI Models Run Slowly

Large language models require considerable memory and processing power. Try choosing a smaller model that better matches your Mac's hardware.

Not Enough Storage Space

AI models can occupy several gigabytes. Remove unnecessary files and make sure you have enough free storage before downloading additional models.

Yes. Once the application and a local model are downloaded, you can use that model offline.

Yes. Current local-model support is designed for Apple Silicon Macs, including M1, M2, M3, and M4 processors.

Can I use Jan AI without coding knowledge?

Yes. Its desktop interface allows beginners to download models and start conversations without writing code.
