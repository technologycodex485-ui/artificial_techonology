What is Things 3?

A personal task manager built around clarity, simplicity, and a more organized approach to everyday life.

Things 3 is a popular productivity application developed by Cultured Code. Designed for Apple's ecosystem, it gives users a structured place to manage personal tasks, work responsibilities, long-term goals, and larger projects.

Instead of keeping reminders scattered across notes, messages, and separate lists, Things lets you collect everything in one organized system. Its clean interface makes it easier to see what needs attention now and what can wait until later.

The app is available separately for Mac, iPhone, iPad, Apple Watch, and Apple Vision Pro. Each version is designed for its device, while Things Cloud can keep supported devices synchronized.

Designed to reduce everyday clutter

A good task manager should help you think clearly rather than create another complicated system to maintain. Things 3 focuses on simple navigation, clear lists, project organization, and flexible scheduling.

Good to know

Is Things 3 worth considering?

Things 3 is particularly appealing to people who value a polished interface and prefer managing their tasks within Apple's ecosystem. Students can organize assignments, professionals can manage projects, and individuals can use it to keep personal responsibilities under control.

Pricing and availability

Things 3 uses a one-time purchase model rather than a recurring subscription. However, the Mac, iPhone, iPad, and Vision versions are sold separately. Things Cloud synchronization is included at no additional charge with the app.

Mac users can also try the official 15-day free trial before purchasing. Always check the official App Store listing and system requirements to confirm compatibility with your device.

Things 3 limitations to consider

Things 3 is designed primarily for individual task management rather than team collaboration. It does not provide a browser-based version or real-time shared task lists. Calendar integration displays events from Apple Calendar rather than connecting directly to every third-party calendar service.

Common questions

Frequently Asked Questions

Helpful answers about Things 3 and its productivity features.

1. What is Things 3 used for?

Things 3 is a personal task management application used to organize to-dos, projects, reminders, and everyday responsibilities.

2. Is Things 3 available for Mac?

Yes. Things 3 has a dedicated Mac application designed for managing tasks and projects on macOS.

3. Does Things 3 require a subscription?

No. Things 3 is sold as a one-time purchase for each supported platform, rather than a subscription.

4. Can Things 3 sync tasks between devices?

Yes. Things Cloud synchronizes your to-dos across supported Apple devices when you sign in and enable synchronization.

5. Does Things 3 work on Windows or Android?

No. Things is made for Apple's platforms and does not offer native Windows or Android applications.

6. Can I try Things 3 before purchasing?

Mac users can access an official 15-day trial with the full feature set before deciding whether to purchase the application.

7. Can I use Things 3 for team collaboration?

Things 3 is primarily designed for individual productivity. It does not currently support real-time collaboration on shared to-do lists.
