About OneDrive

A smarter way to store and access your files

Microsoft OneDrive is a cloud storage and file synchronization service developed by Microsoft. It allows users to upload documents, photographs, videos and other digital files to online storage.

Instead of keeping every important file on a single computer, OneDrive helps you access your content through supported devices and web browsers. Your files can be synchronized between the cloud and your computer using the OneDrive desktop application.

OneDrive also works with Microsoft 365 applications, making it convenient to save, edit and collaborate on documents using services such as Word, Excel and PowerPoint.

Frequently Asked Questions

Common questions about OneDrive

Helpful answers to questions people often ask before using Microsoft's cloud storage service.

1. What is Microsoft OneDrive?

Microsoft OneDrive is a cloud storage service that lets users store, synchronize, access and share files through supported devices and web browsers.

2. Is OneDrive free to use?

Yes. A free Microsoft account includes 5 GB of OneDrive cloud storage. Paid Microsoft 365 plans offer larger storage allowances and additional benefits.

3. Can I use OneDrive on my phone?

Yes. OneDrive has mobile applications for supported iOS and Android devices, allowing users to access, upload and share files.

4. Does OneDrive synchronize files automatically?

The OneDrive desktop application can automatically synchronize files in configured folders when an internet connection is available and synchronization is enabled.

5. Can I share files with other people?

Yes. OneDrive lets you share files and folders using links. Available settings can control who can access shared content and what they are allowed to do.

6. What is OneDrive Personal Vault?

Personal Vault is a protected area within OneDrive that uses additional identity verification to provide an extra layer of protection for selected sensitive files.

7. Can I access OneDrive files offline?

Yes, if you download files or mark supported files and folders for offline availability beforehand. Online-only files require an internet connection to open.

8. Is OneDrive suitable for business use?

Yes. OneDrive for work or school supports business file storage, synchronization and collaboration, with features depending on the organization's Microsoft 365 subscription and configuration.

9. Does OneDrive work with Microsoft Office?

Yes. OneDrive integrates with Microsoft 365 applications, including Word, Excel and PowerPoint, to support saving, accessing and collaborating on documents.
