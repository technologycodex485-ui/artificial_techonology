Introduction

What Is Ice for Mac?

A flexible utility that gives Mac users more control over their menu bar.

Ice is a free and open-source menu bar manager for macOS developed by Jordan Baird. It is designed to help users manage the growing number of icons that appear at the top of a Mac screen. Instead of allowing every application icon to remain visible, Ice provides ways to hide selected items and reveal them whenever they are needed.

Many Mac applications place their own icons in the menu bar. These icons can provide useful shortcuts and status information, but too many of them can make the screen feel crowded. Ice helps create a more organized arrangement by separating visible and hidden items.

Take Control of Menu Bar Icons

With Ice, users can organize menu bar items using a divider and separate sections. Hidden items can be revealed through supported interactions such as hovering, clicking, scrolling, or keyboard shortcuts. Automatic re-hiding helps return the menu bar to its compact appearance after use.

Customize the Appearance

Ice is not limited to hiding icons. It also provides appearance settings that let users adjust the menu bar's visual style. Depending on the available version and settings, these options include tint, borders, shadows, and custom shapes.

Open-Source and Community Driven

Ice is distributed under the GPL-3.0 open-source license. Users can explore its source code and follow development through the project's official repository. The application continues to evolve, so available features may change between releases.

Installation Guide

Installing Ice on macOS

Ice provides more than one installation approach for Mac users.

Option 1: Manual Installation

Visit the official project release page, download the available Ice archive, extract it, and move the application into your Applications folder. Follow any macOS security prompts shown during the first launch.

Option 2: Homebrew

If Homebrew is already installed on your Mac, you can use the following command in Terminal:

brew install --cask jordanbaird-ice

Check the official project documentation for the latest installation instructions and system requirements before installing. Ice requires macOS 14 Sonoma or later.

Help Center

Frequently Asked Questions

Answers to common questions about Ice and its macOS features.

1. What is Ice software?

Ice is a free and open-source menu bar management utility for macOS. It helps users hide, reveal, and organize menu bar icons.

2. Is Ice free to use?

Yes. Ice is distributed as a free and open-source project under the GPL-3.0 license.

3. Does Ice work on Windows?

No. Ice by Jordan Baird is designed for macOS and is not a Windows menu bar application.

4. Which macOS version does Ice require?

Ice requires macOS 14 Sonoma or later. Check the current release information for any updated requirements.

5. Can Ice hide menu bar icons?

Yes. Hiding and revealing menu bar items is one of its primary functions. You can organize icons into sections and access hidden items when needed.

6. What is the Ice Bar?

The Ice Bar is a separate strip where hidden menu bar items can be displayed. It is particularly useful for MacBooks with a display notch.

7. Who develops Ice?

Ice is developed by Jordan Baird and maintained as an open-source project. Its source code and releases are available through GitHub.
