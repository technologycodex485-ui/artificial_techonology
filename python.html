01 / Meet Python

A simple beginning for your coding journey

Python is a widely used, high-level programming language known for its readable syntax and broad ecosystem. It is used in web development, automation, data analysis, artificial intelligence, scientific computing, and many other areas of software development.

Installing Python on a Mac gives you access to the Python interpreter and tools for creating and running Python programs. You can write code in a text editor, use an integrated development environment, or work directly from the Terminal.

The official Python installer is a convenient starting point for beginners who want a straightforward macOS installation without configuring a package manager first.

What can you build?

Python can help you create automation scripts, small desktop tools, web applications, data projects, and prototypes. You can expand its capabilities with third-party packages as your skills grow.

03 / Step-by-Step Setup

How to install Python on your Mac

Follow these steps to download the official installer, complete setup, and check that Python is ready to use.

Your setup checklist

  • 01 — Visit Python.org
  • 02 — Choose a stable release
  • 03 — Download the macOS package
  • 04 — Run the installer
  • 05 — Install certificates
  • 06 — Verify Python
  • 07 — Run your first program
STEP 01

Visit the official Python website

Open the official Python downloads page for macOS. It lists available releases and their corresponding installer packages.

Visit Python Downloads ↗
STEP 02

Choose a stable Python version

Select the latest stable Python 3 release that supports your Mac. Avoid alpha, beta, and release-candidate downloads unless you specifically need to test pre-release software.

STEP 03

Download the macOS installer

Choose the macOS installer package for your selected release. Official universal2 installers are designed to run natively on supported Intel and Apple silicon Macs. Check the release page for its exact compatibility details.

STEP 04

Open the downloaded package

Locate the downloaded .pkg file in your Downloads folder and double-click it. The standard macOS Installer application will guide you through the setup.

STEP 05

Complete the installation

Read the installation information, continue through the setup screens, accept the license terms, and authorize the installation if macOS requests it. Wait for the installer to display its completion message.

STEP 06

Install the certificates

For the standard python.org installation, open the Python version folder in Applications and run Install Certificates.command. This completes the SSL certificate setup for that Python installation.

STEP 07

Verify Python in Terminal

Open Terminal from Applications or Spotlight. Type the following command and press Return:

# Check the installed Python version python3 --version

If Python is installed and available in your shell path, Terminal will display the installed version number.

Important Mac tip

macOS may include an Apple-managed Python-related executable for system or developer tools. Do not delete or modify Apple's system-managed Python installation. Use the python.org installation separately.

Write your first line of Python

05 / After Installation

Useful things to do next

After confirming Python works, these simple habits can help you organize your development environment.

Check pip

Use python3 -m pip --version to check whether the package installer is available for your Python installation.

Create a virtual environment

Use python3 -m venv .venv to create an isolated environment for a project and its packages.

Choose a code editor

You can write Python in IDLE, Visual Studio Code, or another editor that supports Python development.

06 / Frequently Asked Questions

Python installation questions

1. Is Python free to download on Mac?

Yes. Python is open-source software and can be downloaded for free from its official website.

2. Can I install Python on an Apple silicon Mac?

Yes. Official macOS universal2 installers support compatible Apple silicon and Intel Mac computers. Always check the selected release's system requirements.

3. How do I check whether Python is installed?

Open Terminal and run python3 --version. If the command is available, it displays the Python version associated with that command.

4. Do I need to install Python separately from macOS?

For modern Python development, installing a current supported release from python.org is a good approach. Do not modify Apple's system-managed Python tools.

5. What is the best editor for Python on Mac?

Beginners can start with IDLE, which is included with the standard Python distribution. Other popular choices include Visual Studio Code and PyCharm.
