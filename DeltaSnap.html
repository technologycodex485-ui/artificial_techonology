01 / PRODUCT OVERVIEW

What is DeltaSnap?

A native macOS utility that makes filesystem snapshots easier to browse, compare, organize, and restore from.

DeltaSnap is an APFS snapshot manager developed by ScaleNinja. It turns native Apple filesystem snapshots into a practical version-history system for files and folders on a Mac.

With DeltaSnap, users can browse current and deleted files, inspect earlier versions, compare two snapshots, and restore individual items. It can also manage scheduled snapshots and retention settings on supported APFS volumes.

The application is useful for developers, system administrators, content creators, and advanced Mac users who regularly make changes to important files and projects.

DeltaSnap also includes Finder integration and a command-line tool called dsnap, providing additional options for users who want to manage snapshot workflows from scripts and compatible development tools.

A smarter local undo layer

DeltaSnap helps you inspect filesystem history and recover individual files without needing to roll back an entire project or volume.

03 / WORKFLOW

How DeltaSnap works

Understand the basic idea behind creating checkpoints and using filesystem history.

STAGE 01

Create a checkpoint

Create or schedule an APFS snapshot to preserve a point-in-time view of a tracked volume.

STAGE 02

Review what changed

Browse indexed file history and compare snapshots to identify changes between two points in time.

STAGE 03

Recover what matters

Preview earlier versions and selectively restore files that need to be recovered.

Important: Snapshots are not a replacement for backups.

APFS snapshots are stored on the volume they capture. They do not protect against loss or erasure of that disk. Keep an independent external or off-site backup for hardware failure, theft, and disaster recovery.

05 / PRIVACY

Designed around local filesystem data

Understand where DeltaSnap stores information and how it handles your snapshot history.

DeltaSnap is described by its developer as a local-first application. Snapshots, filenames, directory listings, indexes, and schedules remain on the Mac.

According to the developer's privacy policy, the application does not include analytics or telemetry. Its normal network requests are used for license activation or deactivation and checking for updates.

Users who need an offline licensing option can contact the developer to ask about an offline license. Optional email notifications use the mail server configured by the user.

⌑

Local-first approach

Your indexed file history and snapshot contents are designed to remain on your own Mac rather than being uploaded to a cloud storage service.

07 / FAQ

Frequently asked questions

Useful answers to common questions about DeltaSnap.

1. What is DeltaSnap used for?

DeltaSnap manages APFS snapshots and helps users browse file history, compare changes, and recover individual files on macOS.

2. Does DeltaSnap work on Windows?

No. DeltaSnap is a native Mac application and requires macOS 15 or later.

3. Is DeltaSnap a complete backup solution?

No. Snapshots are stored on the source volume and do not survive its loss or erasure. Keep an independent backup for additional protection.

4. Can DeltaSnap recover deleted files?

It can help locate deleted files that are present in indexed snapshot history and recover captured versions. It cannot guarantee recovery of every deleted file.

5. Does DeltaSnap support Finder?

Yes. It provides Finder integration for supported snapshot and recovery actions.

6. Does DeltaSnap have a command-line tool?

Yes. DeltaSnap includes a command-line toolkit called dsnap for users who want to work with snapshots through scripts and terminal workflows.
