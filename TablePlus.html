01 / Introduction

What Is TablePlus?

TablePlus is a modern database management tool designed to make working with databases more convenient. It provides a graphical interface where developers can connect to database servers, browse tables, inspect records, edit data, and execute SQL queries.

Database management is an important part of software development. Websites, mobile applications, business platforms, and online services often rely on databases to store information such as user accounts, product details, transactions, and application settings.

TablePlus brings many common database tasks into one workspace. Rather than switching between multiple command-line tools, developers can use its visual interface to explore database structures and work with records.

Why Do Developers Choose TablePlus?

A good database client can simplify everyday development work. TablePlus combines a native interface with features such as a SQL editor, inline data editing, advanced filters, multiple tabs, and support for different database systems.

It is useful for developers who want a focused environment for managing databases without unnecessary complexity.

Which Databases Does TablePlus Support?

TablePlus supports a wide range of database technologies, including PostgreSQL, MySQL, MariaDB, SQLite, Microsoft SQL Server, Redis, MongoDB, Oracle, Cassandra, Snowflake, and several other systems. Available database drivers can vary depending on the operating system and application version.

03 / SQL Editor

Write and Manage SQL Queries

The SQL editor is an important part of TablePlus. Developers can write queries to retrieve, filter, update, and organize information stored in their databases.

For example, a developer working with a customer database might use a query like the following to retrieve active users.

EXAMPLE SQL QUERY
SELECT
    id,
    name,
    email
FROM
    customers
WHERE
    status = 'active'
ORDER BY
    name ASC;

TablePlus provides an interface for running SQL statements and reviewing query results. Its editor tools can help users write and organize queries more efficiently.

Review Changes Before Committing

One useful aspect of TablePlus is its approach to data changes. Edited records can remain pending until they are committed. Users can preview generated SQL statements or discard changes before applying them to the database.
