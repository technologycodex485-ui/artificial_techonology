Discover Hazel

What Is Hazel for Mac?

A flexible file-management assistant designed to reduce repetitive work and help maintain an organized Mac.

Hazel is a file organization and automation application developed by Noodlesoft for macOS. It monitors folders selected by the user and checks their contents against rules. When a file matches a rule, Hazel can perform the action assigned to it.

For example, you can create a rule that moves PDF invoices into a dedicated folder, renames files according to a naming pattern, or applies Finder tags to specific documents. Instead of manually repeating these actions, you can build a workflow that handles them for you.

Designed for Everyday File Management

Downloads, screenshots, documents, and other files can quickly accumulate in different locations. Hazel helps you establish consistent organization habits by applying the conditions and actions you define. You decide which folders it watches and what should happen when a file meets your criteria.

More Than a Basic File Organizer

Hazel also supports actions such as copying, archiving, opening, uploading, and changing file metadata. Its additional tools include Trash management and App Sweep, which can identify leftover application support files when you remove an app.

Getting Started

How Does Hazel Work?

Start with a folder, define your conditions, and choose the actions Hazel should perform.

STEP 01

Select a Folder

Choose a location you want Hazel to monitor, such as Downloads, Documents, or another folder on your Mac.

STEP 02

Create a Rule

Set conditions that identify the files you want Hazel to recognize, such as a file type or a particular name.

STEP 03

Choose an Action

Decide what happens when a file matches, such as moving it, renaming it, or applying a Finder tag.

Common Questions

Frequently Asked Questions

Helpful answers to common questions about Hazel and its file automation features.

1. What is Hazel software used for?

Hazel is used to automate file organization on Mac. It monitors selected folders and performs actions on files that match rules created by the user.

2. Is Hazel available for Windows?

Hazel by Noodlesoft is designed for macOS. It is not a Windows file-management application.

3. Can Hazel organize files automatically?

Yes. You can configure folder rules that identify files by attributes and automatically move, rename, tag, or perform other supported actions.

4. Can I create my own Hazel rules?

Yes. Hazel allows users to create rules with conditions and actions for the folders they choose to monitor.

5. Does Hazel help clean up the Trash?

Yes. Hazel includes Trash management options that can automatically remove items based on their age or the Trash folder's size.

6. Who develops Hazel?

Hazel is developed by Noodlesoft. Visit the developer's official website for product information, downloads, and documentation.
