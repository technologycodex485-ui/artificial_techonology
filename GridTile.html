01 / INTRODUCTION

What is GridTile?

A keyboard-focused approach to organizing application windows on your Mac.

GridTile is a native macOS window-tiling application developed using Swift, SwiftUI, and AppKit. It provides a menu-bar-based way to move and resize the currently focused application window through a visual keyboard grid.

Rather than memorizing many different shortcuts for left, right, top, bottom, and corner positions, users activate a grid overlay and select two points to define the desired rectangular window area.

GridTile is designed for people who prefer keyboard navigation and want more precise control over their desktop workspace. It is particularly useful when working with multiple applications side by side.

The native version works as a menu bar application without requiring Hammerspoon. Its source code is publicly available, making it interesting for developers who want to inspect or contribute to the project.

03 / HOW IT WORKS

Three steps to a better desktop

GridTile uses a simple activation and selection process.

STEP 01

Activate a layout

Press the configured global shortcut to display the grid overlay on the relevant screen.

STEP 02

Select two cells

Press one or two characters to define the grid region that should contain the focused application window.

STEP 03

Arrange your window

GridTile adjusts the original window to the selected screen area. Press Escape to cancel the selection.

07 / FAQ

Frequently asked questions

Answers to common questions about GridTile.

1. What is GridTile used for?

GridTile is a keyboard-driven macOS utility for moving and resizing application windows using a screen grid.

2. Is GridTile a native Mac application?

Yes. The newer version is built with Swift, SwiftUI, and AppKit as a native menu bar application.

3. Does GridTile require Accessibility permission?

Yes. macOS Accessibility permission is needed to reposition and resize windows belonging to other apps.

4. Does GridTile require Hammerspoon?

The native GridTile application is designed to run independently without requiring Hammerspoon.

5. Can I customize keyboard shortcuts?

Yes. The native project includes configurable global activation shortcuts and grid layout settings.

6. Is GridTile free?

The native project is published under the MIT open-source license. Check its repository for the latest release and distribution information.

7. Where can I download GridTile?

Visit the official project website or GitHub repository to find its source code and available releases.
