How to Install Homebrew on Mac

A beginner-friendly guide to installing Homebrew on macOS. Learn how to set up your package manager, run Terminal commands, and install useful developer tools.

Start Installation Guide →

Homebrew is one of the most useful tools for Mac users who want more control over their software and development environment. It is a popular package manager that makes installing, updating, and managing command-line tools and applications much easier.

If you are a developer, programmer, or everyday Mac user interested in learning new software tools, installing Homebrew can make your workflow more convenient. In this guide, we explain how to install Homebrew on Mac using simple Terminal commands.

What Is Homebrew on Mac?

Homebrew is a free and open-source package manager for macOS. It allows users to download and manage software directly from the Terminal without manually searching for installation files.

For example, instead of downloading a command-line utility from a website, you can install supported packages using a simple command such as brew install wget.

Homebrew also helps manage software updates and dependencies, making it a useful tool for people working with programming languages, development environments, and command-line applications.

Why Should You Install Homebrew?

  • Install useful command-line tools quickly.
  • Manage software packages from Terminal.
  • Update installed packages with simple commands.
  • Install supported Mac applications using casks.
  • Manage development tools and dependencies.
  • Make repetitive software setup tasks easier.
Important: Homebrew is a package manager, not an app store. It installs software from its supported repositories and other configured sources.

Requirements Before Installing Homebrew

Before starting the installation, make sure your Mac meets the requirements for the Homebrew version you plan to install.

  • A compatible Intel or Apple Silicon Mac.
  • A supported version of macOS.
  • An active internet connection.
  • Access to the macOS Terminal.
  • Command Line Tools for Xcode when required.

You can check the latest compatibility information on the official Homebrew installation documentation .

How to Install Homebrew on Mac

Follow the instructions below to download and install Homebrew on your Mac.

01 Open Terminal

First, open Finder and navigate to Applications. Select Utilities and launch Terminal. You can also press Command + Space, search for Terminal, and press Enter.

02 Install Command Line Tools

Homebrew may need Apple's Command Line Tools. If they are not already installed, enter this command in Terminal:

TERMINAL COMMAND
xcode-select --install

Follow the installation instructions if macOS displays a confirmation window. If the tools are already installed, you can continue.

03 Run the Homebrew Installation Command

Visit the official Homebrew installation page or use the official installation command below. Copy the command, paste it into Terminal, and press Enter.

OFFICIAL HOMEBREW INSTALL COMMAND
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

The installer explains the changes it plans to make and asks you to confirm before proceeding. Read the instructions and enter your Mac account password if requested.

04 Complete the Installation

Allow the installer to download and configure Homebrew. The time required depends on your internet connection and Mac configuration.

When the installation finishes, carefully read the final Terminal instructions. You may need to configure your shell environment before the brew command becomes available.

Configure Homebrew on Apple Silicon Mac

If you are using an Apple Silicon Mac with an M-series processor, Homebrew normally installs in the /opt/homebrew directory.

If the installer asks you to configure your shell, use the following commands:

APPLE SILICON SETUP
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

Configure Homebrew on Intel Mac

Intel-based Macs normally use /usr/local as the default Homebrew installation prefix.

If the installer instructs you to configure your shell environment, the following commands can be used:

INTEL MAC SETUP
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile eval "$(/usr/local/bin/brew shellenv)"
Remember: Use the configuration that matches your actual installation location. If the installer prints different shell setup instructions, follow its instructions instead.

How to Check If Homebrew Is Installed

After installation and shell configuration, verify that Homebrew is working correctly. Enter the following command:

CHECK HOMEBREW VERSION
brew --version

If the command displays a Homebrew version, the installation is working.

You can also run the following command to check your Homebrew environment:

DIAGNOSTIC COMMAND
brew doctor

This command checks for potential configuration issues and provides suggestions when necessary.

How to Install Software Using Homebrew

Once Homebrew is installed, you can use it to install a variety of supported tools and packages. Here are some useful examples.

Install wget

INSTALL PACKAGE
brew install wget

Install Git

INSTALL PACKAGE
brew install git

Install Node.js

INSTALL PACKAGE
brew install node

Update Homebrew

UPDATE HOMEBREW
brew update

Upgrade Installed Packages

UPGRADE PACKAGES
brew upgrade

Common Homebrew Installation Problems

1. Brew Command Not Found

If Terminal displays a message saying that the brew command cannot be found, your shell environment may not be configured correctly. Review the post-installation instructions and add the correct Homebrew shellenv command.

2. Command Line Tools Are Missing

Homebrew may require Apple's Command Line Tools for certain operations. Run xcode-select --install if they are missing and follow the installation prompts.

3. Internet Connection Problems

A weak internet connection can interrupt downloads. Check your network connection and try again. If GitHub is unavailable, wait until connectivity is restored.

4. Permission Errors

Permission problems can occur when Homebrew's installation directory has incorrect ownership or permissions. Follow the official Homebrew troubleshooting documentation rather than changing permissions randomly or running every brew command with sudo.

Frequently Asked Questions

Is Homebrew free to use?

Yes. Homebrew is free and open-source software. Users can install and manage supported packages without purchasing a Homebrew license.

Can beginners install Homebrew on Mac?

Yes. Beginners can install Homebrew by following the official Terminal instructions. Basic knowledge of copying and running commands is helpful.

Is Homebrew available on Apple Silicon Macs?

Yes. Homebrew supports Apple Silicon Macs and normally uses the /opt/homebrew installation directory.

Can I install applications using Homebrew?

Yes. Homebrew supports command-line packages called formulae and many Mac applications through casks.

How do I update Homebrew?

Open Terminal and enter brew update to fetch the latest Homebrew package information. You can use brew upgrade to upgrade installed packages.

Does Homebrew replace the Mac App Store?

No. Homebrew is a separate package manager designed primarily for developer tools, command-line utilities, and supported applications.
