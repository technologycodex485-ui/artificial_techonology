Product overview

What Is Raycast?

A versatile launcher designed to help you find information, access tools, and complete everyday computer tasks from a single interface.

A smarter way to interact with your computer

Raycast is a productivity application that provides a keyboard-driven command interface. Rather than opening multiple menus and searching through different applications, users can bring up Raycast, type a command, and quickly access the action they need.

It can search for applications and files, perform calculations, open websites, manage windows, retrieve copied content, and run commands from installed extensions. This makes it a useful tool for people who want a more efficient desktop workflow.

Search applications, files, and commands

Raycast's launcher is built around fast search. Start typing the name of an application, file, folder, or command to find a relevant result. You can also use Quicklinks to open frequently visited websites, specific URLs, and other destinations with custom names or shortcuts.

The action panel provides additional options for selected results. This means you can do more than simply open an item: depending on the result, you can configure a hotkey, copy information, or perform another available action.

Customize your workflow with extensions

One of Raycast's most useful features is its extension ecosystem. Extensions add commands and integrations for different applications and services. Users can discover community-built tools for productivity, engineering, design, writing, entertainment, and other categories.

For example, supported extensions can help you interact with services such as Linear, Slack, Spotify, and other connected applications. The exact actions depend on the extension and the permissions or account access it requires.

Clipboard history and text snippets

Raycast's Clipboard History helps you find content you copied earlier. It can store copied text, images, files, links, emails, and other supported content. Instead of copying the same information again, you can search your history and retrieve an earlier item.

Snippets are another useful productivity feature. Save frequently used phrases, email responses, code fragments, or other text and insert them using a configured keyword. This can save time when repeating common writing tasks.

Raycast AI: assistance from your launcher

Raycast AI brings AI-powered assistance into the same environment as your commands and extensions. Depending on your plan and configuration, you can use Quick AI for short questions or AI Chat for longer conversations.

AI capabilities can include writing assistance, summarization, coding help, image generation, connected tools, and context from supported files or your screen. Available models, usage credits, and advanced capabilities vary by subscription tier.

Window management and everyday utilities

Raycast includes built-in tools that reduce the need to open separate applications for simple tasks. Its window management commands can move and resize windows, while the calculator can evaluate expressions and perform conversions directly from the launcher.

Other useful features include Emoji Picker, Quicklinks, Notes, developer tooling, and system commands. Together, these features make Raycast more than a basic application launcher.

Raycast for different platforms

Raycast has expanded beyond its original Mac experience. Its product lineup includes Windows and iOS experiences, with feature availability varying by platform and release. Some newer features are platform-specific, so check the official requirements before installing.

Is Raycast worth using?

If you regularly switch between applications, use keyboard shortcuts, repeat text, manage copied content, or rely on several online tools, Raycast can make those activities more convenient. Its free plan offers many core features, while paid subscriptions add AI and advanced capabilities.

Frequently asked questions

Raycast FAQ

Answers to common questions about Raycast, its features, compatibility, and subscriptions.

1. What is Raycast used for?

Raycast is a productivity launcher used to search applications and files, run commands, manage windows, retrieve clipboard history, use extensions, and access other desktop tools.

2. Is Raycast free?

Yes. Raycast Free includes many core productivity features and community extensions. Paid subscriptions unlock Raycast AI and additional features.

3. Does Raycast support AI?

Yes. Raycast AI includes features such as Quick AI, AI Chat, AI Commands, and supported AI integrations. AI access and usage credits depend on your subscription.

4. Can I install extensions in Raycast?

Yes. Raycast has an extension store containing community-built integrations and commands. You can browse and install extensions that match your workflow.

5. Does Raycast have clipboard history?

Yes. Clipboard History lets you search and reuse previously copied content. The free plan has a retention limit, while paid plans offer unlimited clipboard history.

6. Is Raycast available on Windows?

Yes. Raycast has expanded to Windows as well as macOS and iOS. Features and availability can differ between platforms and versions.

7. What macOS version does Raycast require?

Raycast V1 currently requires macOS 13 or later. The newer Raycast V2 requires macOS Tahoe and Apple Silicon. Check the official download page to confirm which version is appropriate for your Mac.

8. Can I create my own Raycast extensions?

Yes. Raycast provides developer tooling and an extension API. Developers can build custom commands and integrations and publish eligible extensions to the Raycast Store.

9. Is Raycast a replacement for Spotlight?

Raycast can be configured as an alternative launcher to Spotlight. It provides additional commands, extensions, shortcuts, and customization options.
