01 / Introduction

What is VolEq?

VolEq stands for Volume Equilibrium. It is a lightweight audio application for Mac that focuses on automatic voice-volume leveling, especially in online meetings and voice conversations.

The software aims to make quieter speech easier to hear while keeping louder speech under control. Its speech-aware processing can also apply mild noise suppression when speech and background noise are detected together.

The Community edition is open source and designed for Apple Silicon Macs. It offers a native application experience through a regular window or menu-bar interface.

Less volume adjusting. More attention on the conversation.

VolEq works on the combined captured audio mix. It does not independently change the volume of each person in a meeting.

02 / Core capabilities

Features designed for balanced listening

VolEq focuses on voice clarity, local processing and a more consistent listening experience. Here are some of its key capabilities.

FEATURE 01

Automatic Voice Leveling

Raises quieter speech and controls louder speech to help maintain a steadier listening level.

FEATURE 02

Speech-Aware Processing

The processing is designed to distinguish speech from background noise before applying quiet-speech gain.

FEATURE 03

Peak Protection

Linked-stereo leveling and lookahead peak protection help keep sudden loud peaks under control.

FEATURE 04

Flexible Audio Capture

Capture one active audio-producing application or the complete device-wide output mix.

FEATURE 05

Native Mac Interface

Access the application through a focused window or a convenient menu-bar presentation.

FEATURE 06

Local Audio Processing

Captured audio is processed in memory on the Mac, without an online speech-processing service.

03 / Getting started

A simple workflow for clearer audio

The basic setup involves installing the application, choosing an audio capture mode and allowing macOS to provide the required recording permission.

Install VolEq

Download the macOS release from the project's official GitHub release page and move the application into Applications.

Allow Audio Access

Launch VolEq and follow the macOS System Audio Recording permission prompt to enable audio capture.

Choose Your Capture Mode

Select an active application or device-wide output capture, then use the application to manage voice leveling.

05 / Privacy approach

Audio stays on your Mac

The VolEq Community project describes a local-first privacy approach. Captured audio is processed in memory rather than sent to an online speech service.

  • No account is required.
  • No audio recording is part of its stated design.
  • No usage telemetry is described by the project.
  • Optional update checks require user consent.

07 / Questions and answers

Frequently asked questions

1. What does VolEq do?

VolEq automatically levels voice volume on a Mac, helping make quieter speech easier to hear and louder speech more controlled.

2. Is VolEq open source?

Yes. The VolEq Community repository and its source and documentation are published under the Mozilla Public License 2.0, subject to the project's stated exceptions.

3. Does VolEq work on Windows?

The Community project's current platform information lists macOS as supported, while Windows and Linux are planned rather than currently available.

4. Does VolEq upload my audio?

The Community project says captured audio is processed locally in memory and is not sent to an online speech service.

5. Is VolEq the same as the Android app?

No. There is also an Android app named VolEq - Volume Balancer, which uses presets such as Podcast, Noisy, Balanced and Custom. This article focuses on the separate macOS Community project.

6. Where can I find the macOS release?

Visit the official GitHub releases page to review the available release, installation instructions and compatibility information.
