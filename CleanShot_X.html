Product overview

What Is CleanShot X?

A closer look at the Mac utility that turns everyday screen captures into useful, polished visual communication.

A complete screenshot solution for Mac

CleanShot X is a screenshot and screen recording application designed specifically for Mac users. It provides tools for capturing screen content, editing images, recording demonstrations, and sharing visual information.

Instead of switching between multiple applications to capture, crop, annotate, and distribute an image, users can complete many of these tasks within a single workflow. This makes it useful for people who regularly explain ideas through screenshots and screen recordings.

More than a basic screenshot tool

The built-in macOS screenshot utility is convenient for simple captures. CleanShot X expands that workflow with additional capture modes, editing tools, scrolling screenshots, text recognition, and sharing options.

You can capture a selected area, an application window, or the entire display. For content that extends beyond the visible screen, scrolling capture can help create one longer image.

Make screenshots easier to understand

A screenshot is most useful when the important information is easy to identify. CleanShot X includes annotation tools that help users add arrows, highlights, text, shapes, and numbered steps. You can also blur or pixelate information that should not appear in the final image.

The Background Tool provides additional presentation options, including padding, alignment, aspect ratios, and backgrounds. These features can help turn an ordinary capture into a professional-looking visual for documentation, presentations, or social media.

Screen recording and video editing

CleanShot X also supports screen recording. Users can record a selected area, a window, or the full display. Recording options include microphone audio, computer audio, webcam overlays, cursor visibility, and click or keystroke indicators.

Its built-in video editor includes Studio Mode, which offers tools such as trimming and animated zoom effects. This is especially useful when creating software demonstrations, product walkthroughs, and instructional videos.

Text recognition and quick sharing

The OCR feature can recognize text inside screenshots and images, allowing users to copy information without manually typing it again. CleanShot also supports QR code recognition. According to its feature documentation, text recognition is performed on-device.

For sharing, CleanShot Cloud can upload captures and generate links. Cloud features vary by plan and can include video transcription, comments, access controls, and password protection.

Frequently Asked Questions

Helpful answers to common questions about CleanShot X.

1. What is CleanShot X used for?

CleanShot X is a Mac application used for taking screenshots, recording the screen, editing captures, adding annotations, recognizing text, and sharing visual content.

2. Is CleanShot X available for Windows?

No. CleanShot X is designed for macOS and does not currently offer a Windows version.

3. Does CleanShot X support scrolling screenshots?

Yes. Its scrolling capture feature can capture content that extends beyond the visible area of a window, including long pages and documents.

4. Can I record videos with CleanShot X?

Yes. You can record selected screen areas, windows, or the full display. Recording options include audio and webcam overlays.

5. Does CleanShot X include an image editor?

It includes an annotation editor with tools for cropping, adding text, drawing arrows, highlighting details, and hiding sensitive information.

6. Does CleanShot X have a free trial?

The official pricing FAQ currently says there is no direct free trial. Purchases include a 30-day money-back guarantee. Availability through Setapp may include a separate trial.

7. What macOS version does CleanShot X require?

The current official requirement is macOS 13.0 or newer. Check the official website for updated compatibility information before installing.

8. Do I need CleanShot Cloud to use the application?

No. CleanShot Cloud is used for uploading and sharing captures. The official FAQ states that a Cloud account is not required for the app's other features.
