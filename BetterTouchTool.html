What Is BetterTouchTool?

BetterTouchTool is a macOS customization and automation application developed by Folivora AI. It helps users personalize how they control their Mac by connecting gestures, mouse inputs, keyboard shortcuts, and other triggers to useful actions.

Instead of relying only on the default macOS controls, you can create your own interactions. For example, a trackpad gesture can open an application, a keyboard shortcut can organize a window, or a mouse button can trigger a multi-step workflow.

BetterTouchTool is particularly useful for people who spend many hours working on a Mac and want their everyday actions to feel faster, more consistent, and easier to control.

Why Do Mac Users Choose BetterTouchTool?

The biggest advantage is flexibility. You can start with one simple shortcut and gradually build more advanced configurations as your needs change. Its triggers and actions can also be combined, making it useful for both everyday productivity and specialized workflows.

Common Questions

Frequently Asked Questions

A few helpful answers before you start using BetterTouchTool.

What is BetterTouchTool used for?

BetterTouchTool is used to customize Mac input devices, create keyboard shortcuts, configure gestures, manage windows, and automate different tasks.

Does BetterTouchTool work with MacBook trackpads?

Yes. It supports custom gestures for built-in MacBook trackpads and Apple's Magic Trackpad.

Can I customize my mouse with BetterTouchTool?

Yes. You can assign actions to supported mouse buttons and configure additional mouse interactions.

Does BetterTouchTool support keyboard shortcuts?

Yes. It supports global and app-specific shortcuts, along with other keyboard-based triggers.
